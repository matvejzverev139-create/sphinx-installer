# Автоответчик для Telegram Chat Automation

Бот отвечает в твоём стиле через бесплатный Groq API. Telegram сам решает,
когда его подключать (через Settings → Chat Automation) — код бота не
привязан к таймерам.

## Шаг 1. Создать бота в Telegram

1. Напиши в Telegram **@BotFather**
2. Команда `/newbot`
3. Придумай имя и юзернейм (должен заканчиваться на `bot`, например `my_autoreply_bot`)
4. BotFather пришлёт токен вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ` — сохрани его

## Шаг 2. Получить бесплатный Groq API ключ

1. Зайди на https://console.groq.com
2. Зарегистрируйся (можно через Google)
3. Слева найди **API Keys → Create API Key**
4. Скопируй ключ (он показывается один раз)

## Шаг 3. Задеплоить на PythonAnywhere

1. Зарегистрируйся на https://www.pythonanywhere.com (Free аккаунт)
2. Открой **Consoles → Bash**
3. Загрузи файлы `bot.py` и `requirements.txt` (через Files → Upload a file,
   либо через `git clone`, если выложишь код в свой репозиторий)
4. В консоли выполни:
   ```
   pip install --user -r requirements.txt
   ```
5. Задай переменные окружения прямо перед запуском (замени на свои значения):
   ```
   export TELEGRAM_TOKEN="твой_токен_от_botfather"
   export GROQ_API_KEY="твой_ключ_groq"
   ```
6. Запусти бота:
   ```
   python3 bot.py
   ```

### Важный нюанс с бесплатным тарифом PythonAnywhere

Free-аккаунт не гарантирует, что консоль будет работать бесконечно —
процесс может остановиться при простое. Для действительно стабильной
работы 24/7 обычно нужен **Always-on task** (платная опция) либо другой
бесплатный хостинг с поддержкой долгоживущих процессов (например, Railway
или Render — у них тоже есть free tier, но с своими лимитами по часам).

Если бот всё же "уснёт" — просто зайди в консоль и запусти `python3 bot.py`
заново.

## Шаг 4. Подключить бота в Telegram

1. В Telegram: **Settings → Chat Automation**
2. Впиши юзернейм своего бота в поле **Bot Username or Link**
3. Выбери:
   - **All private chats except...** — бот отвечает везде, кроме
     исключений (добавляешь их ниже, в "Excluded chats")
   - **Only selected chats** — бот отвечает только в выбранных чатах
4. Сохрани настройки

Дальше Telegram сам решает, когда включать бота (например, если ты долго
не заходишь в приложение) — ничего дополнительно настраивать в коде не
нужно.

## Как поменять стиль ответов

Открой `bot.py`, найди переменную `STYLE_PROMPT` — это текстовое описание
твоей манеры общения для ИИ. Можешь дополнить его своими примерами фраз,
чтобы ответы были ещё точнее.
