# Vault Assist (Fabric, клиентский мод, Minecraft 1.21.4)

Что делает: когда включён (клавиша R), стоите рядом с зловещим хранилищем, в руке зловещий ключ,
а над хранилищем показано тяжёлое ядро, мод сам использует ключ на хранилище.

## Сборка
1. Установите JDK 21.
2. В папке проекта: `gradle build` (или добавьте gradle wrapper: `gradle wrapper`, затем `./gradlew build`).
3. Готовый файл: `build/libs/vaultassist-1.0.0.jar` -> в папку mods вместе с Fabric API.

## Важно
- Работает только если показанный предмет действительно совпадает с наградой. Если нет, мод будет просто тратить ключи.
  Проверьте на одном ключе: запомните предмет над хранилищем и сравните с выпавшим.
- На публичных серверах такое запрещено и ведёт к бану. Используйте в одиночной игре или на своём сервере.
- Для другой версии Minecraft поменяйте версии в gradle.properties; в новых версиях (1.21.9+) конструктор KeyBinding
  принимает категорию иначе, и названия могут отличаться.
- Целевой предмет меняется в константе TARGET в VaultAssistClient.java.
