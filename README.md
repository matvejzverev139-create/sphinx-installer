# 🐰 Сфинксляндия Installer

Простой установщик для игры на сервере **Сфинксляндия** (`FatSphynx.gomc.me`).
Нажимаешь кнопки — он всё делает сам.

## Что он делает

1. Находит твой лаунчер Minecraft Java Edition
2. Ставит голосовой чат — мод [Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)
3. Добавляет сервер в список серверов игры
4. Если у тебя ещё нет сборки с модами — создаёт её сам (Fabric, Forge или NeoForge)

## Как пользоваться

1. Скачай `SphinxInstaller.exe` из раздела **Releases** (справа на странице репозитория)
2. Запусти и следуй шагам: **Лаунчер → Сборка → Установка → Готово**
3. В игре: **Сетевая игра → Сфинксляндия**
4. Нажми **V** в игре, чтобы настроить микрофон

> Windows может показать синее окно «Windows защитил ваш компьютер» — файл не подписан.
> Нажми **Подробнее → Выполнить в любом случае**.

## Какие лаунчеры поддерживаются

| Лаунчер | Поиск сборок | Создание новой сборки |
|---|---|---|
| Официальный Minecraft Launcher, TLauncher, SKLauncher (папка `.minecraft`) | ✅ | ✅ |
| Prism Launcher, PolyMC, MultiMC | ✅ | ✅ |
| Modrinth App | ✅ | ❌ (создай сборку в самом лаунчере) |
| CurseForge | ✅ | ❌ |
| ATLauncher, GDLauncher | ✅ | ❌ |

Нужного лаунчера нет в списке? Нажми **«Найти папку самому»** и выбери папку лаунчера или сборки.

## Движки для модов (при создании новой сборки)

| Движок | Плюсы | Минусы |
|---|---|---|
| **Fabric** ⭐ | Самый лёгкий и быстрый, Java не нужна, новые версии первыми | Некоторых больших старых модов нет |
| **Forge** | Больше всего модов, большие сборки | Грузится дольше, для новейших версий может не быть |
| **NeoForge** | Современная ветка Forge, активно развивается | Модов меньше, для новейших версий бывает в тесте |

Версии игры: **самая новая** (узнаётся автоматически) и **1.21.11**.

## Языки

Русский, English, Українська. Язык выбирается по системе, переключить можно кнопками **RU / EN / UK** в углу окна.

Чтобы добавить язык: скопируй один блок внутри `STR` в `sphinx_installer.py`, переведи и добавь строку в `LANGS`.

## Как собрать самому

Нужен Python 3.10+ (только для сборки, для запуска готового exe он не нужен).

```
pip install pyinstaller
pyinstaller --onefile --noconsole --icon icon.ico --name SphinxInstaller sphinx_installer.py
```

Готовый файл появится в `dist/SphinxInstaller.exe`.

Без ПК: любой пуш в репозиторий запускает сборку в **GitHub Actions** (`.github/workflows/build.yml`). Готовый exe лежит в **Actions → последний запуск → Artifacts**.

## Если что-то пошло не так

- **«Не нашёл ни одного лаунчера»** — поставь лаунчер (кнопки скачивания есть в программе) и нажми «Проверить снова»
- **«Для этой версии нет голосового чата»** — мод ещё не вышел для самой новой версии игры, выбери 1.21.11
- **Не получилось установить Forge/NeoForge** — попробуй Fabric или другую версию
- **Не заходит на сервер** — на сервере тоже должен стоять Simple Voice Chat, а порт UDP 24454 должен быть открыт (это нужно только для голоса)

## Важно

Установщик не трогает твои миры и сохранения. Перед каждым изменением `servers.dat` и `launcher_profiles.json` он делает копию с расширением `.bak`.
